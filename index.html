03 / TROUBLESHOOTING

Problems are part of the project.

The most valuable part of the lab is the diagnostic process: observe → isolate → test → fix → document.

01

Ethernet connectivity

Diagnosed interface state, addressing, gateway and routing issues. A Raspberry Pi was configured as a temporary router/gateway to restore connectivity.

ip addr · ip route · ping · systemctl
02

Proxmox console

Investigated why qm terminal 100 failed and learned the relationship between VM console access and serial interfaces.

qm config 100 · serial0 · console
03

Linux permissions

Resolved a sudo access problem by understanding users, groups, ownership and the sudoers model instead of treating permissions as magic.

id · groups · sudo · ls -l
04

Storage capacity

Inspected the block-device hierarchy and expanded the logical volume so the filesystem could use the available storage.

lsblk · vgs · lvs · lvextend
05

VPN routing

Investigated the performance and network path of qBittorrent through Mullvad while keeping the VPN isolated inside the Debian workload.

ip route · traceroute · service logs
